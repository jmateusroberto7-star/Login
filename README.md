# Sistema de Login - Interface, Validação e Navegação
## Funcionalidades implementadas:
Inferface visual
- Caixa de login centralizada com design harmonioso
- Imagem de fundo fixa cobrindo toda a tela
- Fundo escuro semitransparente com sombra para destaque do contéudo
- Campos de formulário claros e intuitivos
- Botão de ação com feedback visual

   ## Lógica de Funcionamento
  - Cadastro de usuário de exemplo em memória
  - Leitura dos dados inseridos pelo usuário
  - Comparação entre os dados digitados e os cadastrados
  - Feedback claro: mensagem de sucesso ou de erro
  - Redirecionamento automático após confirmação de acesso
 
    ## Aprendizados obtidos:
    - Como estruturar um formulário de Login em HTML
